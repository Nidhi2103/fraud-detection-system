# Autonomous Fraud Detection System

This project detects fraudulent financial transactions using Machine Learning and a Streamlit dashboard.

## Features
- Fraud detection using Random Forest
- Behavioral analysis
- Risk scoring
- Explainable AI
- Interactive dashboard

## Technologies
- Python
- Streamlit
- Scikit-learn
- Pandas

## How to Run
1. Install dependencies:
   pip install -r requirements.txt

2. Run the application:
   streamlit run app.py
